# ColinGPT

A mobile-first, iMessage-style chat site. Text "Colin" and get a random canned catchphrase back.

## Editing Colin's catchphrases

Open [`catchphrases.js`](catchphrases.js) and edit the `CATCHPHRASES` array — one string per line. Changes take effect on the next page load.

## Running locally

```
python3 -m http.server
```

Then open http://localhost:8000 in a browser (use device emulation / a narrow window to preview the mobile layout).

## Deployment

Hosted via GitHub Pages from the `main` branch root.
