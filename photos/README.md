Drop Colin's photo files in this folder, then list their filenames in [`../photos.js`](../photos.js) like:

```js
const CONTACT_PHOTOS = [
  "photos/colin1.jpg",
  "photos/colin2.jpg",
];
```

One is picked at random for the header avatar each time Colin sends a new message. Delete this README (or leave it — it's not loaded by the site) once you've added real photos.
